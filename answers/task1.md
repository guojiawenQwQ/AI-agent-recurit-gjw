# Task 1：从 C 源码到可执行文件

请用自己的语言简要说明下面几个阶段分别做了什么：

1. 预处理
2. 编译
3. 汇编
4. 链接

建议控制在 300～500 字，不需要展开复杂细节。

一个 C 程序从源文件到可执行文件，大致经过四个阶段。

1. **预处理**（`gcc -E`）  
   读入 `.c` 源码，处理以 `#` 开头的预处理指令：展开 `#include` 引入的头文件、替换 `#define` 宏、处理条件编译（如 `#ifdef`），并去掉注释。输出仍是文本，扩展名为 `.i`。

2. **编译**（`gcc -S`）  
   对预处理后的代码做语法与语义检查，把 C 代码翻译成汇编代码，生成 `.s` 文件。

3. **汇编**（`gcc -c`）  
   汇编器把汇编指令翻译成机器码，生成二进制目标文件 `.o`。此时各函数、全局变量的地址往往还未最终确定。

4. **链接**  
   链接器把多个 `.o` 以及需要的系统库（如含 `printf` 的库）合并在一起，解析并重定位符号引用，补全缺失的函数地址，最终生成可执行文件。

**流程示意：**  
`hello.c` → 预处理 → `hello.i` → 编译 → `hello.s` → 汇编 → `hello.o` → 链接（含库中的目标文件）→ `hello`（可执行文件）
